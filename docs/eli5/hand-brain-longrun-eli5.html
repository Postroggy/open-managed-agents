脑想、手做

🧠

官方：Anthropic 控制面 · OMA：Go 服务
🤔 想模型推理、决定下一步做什么
🧭 状态会话历史、事件流、Session 生命周期
⚡ 优化prompt caching / compaction

⬇️ 指令
事件流
（唯一通道）
⬆️ 结果
🖐️
手（Worker / 沙箱）
官方：云沙箱 · OMA：Claude Code worker
🛠️ 做工具执行、运行代码、操作文件
💻 跑 bash命令执行、进程管理
🌐 上网网络访问（白名单控制）
📚 技能skill 执行、多 agent 委托

🔑 关键：脑和手不直接接触——脑不碰你的文件系统，手不碰你的模型密钥。 中间只有事件流（`/v1/code/sessions/{id}/worker/*`）。这就是安全的根本。

第五章 · 设计哲学总结

一句话版本

🎯 Managed Agents 的设计哲学 = "手脑分离的托管 agent 基础设施"：

🧠 脑想 —— 推理/状态/事件（host）
🖐️ 手做 —— 工具/代码/文件（worker）
🔗 事件流连接 —— 唯一通道，安全隔离
💤 可暂停可恢复 —— 沙箱 pause、Session 持久
⏳ 天然 Long-run —— 隔天回来任务还在原地

对比 Messages API：DIY agent loop（你写循环、你管沙箱、你处理工具）→ Managed Agents 全部托管（你只定义 Agent + 环境，然后发事件收事件）
