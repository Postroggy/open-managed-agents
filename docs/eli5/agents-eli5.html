🤖 agents AI 智能体

就是「会自己干活的小机器人」

🤖
Agent = 一个能思考、能动手的小帮手
给它一个名字、一个大脑（模型）、一些本领（技能），
它就能自己去完成你交代的任务 💪
🤖 它能干什么？
🛠️

配备本领

给机器人装上工具和技能，让它会查资料、会写代码、会操作

👥

团队协作

一个 agent 可以召唤多个小 agent（multiagent），组成团队干活

🔗

连接外部

通过 MCP 服务器连接外面的工具，就像给它装上手和脚

🧠

有自己的记忆

可以配一个记忆库，记住以前做过的事，越用越聪明

🚀

部署上线

做好了可以发布出去，让其他人都能用

📸

版本留档

每次修改都拍快照，出问题可以看之前的版本

🧩 一个 agent 由什么组成？
🏷️
name
名字（就像起小名）
🧠
model
大脑：用哪个大模型思考
📜
system
人设：告诉它怎么说话、守规矩
🔧
tools
工具：能调用的 API/操作
📚
skills
技能：装上的本领包
🌐
mcp_servers
外接工具服务器
👥
multiagent
小队名单：能召唤哪些帮手
📝
metadata
小纸条：备注和标签

🤝 它和兄弟们怎么配合？
🤖 agents = 机器人本尊
负责被创建、被管理
💬 sessions = 对话记录本
agent 干活时说话都记在这里
📁 files = 文件柜
agent 生成的文件存在这里
🧠 memory = 记忆盒子
agent 把重要的东西记住
一句话：agents = 你雇佣的 AI 打工人 🤖💼
