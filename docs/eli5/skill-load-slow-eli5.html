💥 为什么不能当场做？
🌐

网络不可靠

E2B 服务可能在另一台机器/机房，随时超时断连，当场做会拖垮创建请求

🛠️

是「创建」不是「读」

卷不存在要 CreateVolume（云端建资源），有状态、可能失败、要重试

📦

体积大

技能是完整工具包（archive 压缩包），不是几 KB 配置，要整个传过去

💡 代码里的聪明设计：卷缓存 + 指纹判断
🔍 先查指纹

manifest 的 sha256 当作卷名 —— 相同技能组合复用同一个卷，不用重写

✅ 卷已 ready 就跳过

卷存在且 ready 标记 = 当前指纹 → 直接返回，零写入！

🖊️ 不 ready 才写

标记不匹配 → 才真正把技能包写进远端卷（慢路径）

🎡 慢路径交给队列

第一次加载慢 → 丢队列后台做；之后全命中缓存，秒开
