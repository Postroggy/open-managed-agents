第一章 · 它是什么

Environment 是什么？

Agent 要跑代码，得有个 沙箱小屋（E2B 环境）。
environments 就是负责 盖房子 + 安排施工 的包。

Environment = 一个沙箱环境（云端的临时小电脑）
Work = 环境里的一次任务（跑一个 agent 会话）

它管「环境的一生」：创建 → 轮询任务 → 干活 → 停止 → 清理

第四章 · 和兄弟配合

它和 codesessions 什么关系？

environments = 盖房子的（建沙箱、装包、启动）
codesessions = 住进去的（沙箱里 Claude 的会话、事件、代理）
e2bruntime = 建材商（E2B 沙箱提供商）

environments 通过 CodeSessionRuntime 接口调用 codesessions 创建代码会话 —— 两个包是「先有房、再入住」的接力关系。
