第一章 · 它是什么

为什么需要「代码会话」？

一个 Agent 不只会聊天 —— 它要 真的跑代码、操作文件。
这些活不能在你电脑上干，要放到 云端沙箱 里。

codesessions 就是连接「主服务」和「沙箱里的 worker」的 中枢神经：

🖥️ 主服务 ──通讯── 🤖 沙箱 worker
（30+ 个文件的大包，负责所有消息、事件、日志的流转）

第四章 · 内部结构

零件清单

第五章 · 和兄弟们配合

它和 sessions 什么关系？

sessions = 面向用户的对话会话（对外 API）
codesessions = 背后的代码执行会话（沙箱 + worker）
一个对外会话，背后可能对应一个代码会话

codesessions 是 sessions 的「发动机」——用户看到的是 sessions，跑起来的是 codesessions。
