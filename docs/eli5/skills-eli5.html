第一章 · 它是什么

技能是什么？

Agent 要会干活，得有 技能（Skill）。
skills 包管技能的一生：上传 → 版本 → 打包 → 挂载到沙箱。

internal/skills = 技能管理 API（7 个文件）：

📦 技能包 —— 用户上传 ZIP（SKILL.md + 资源文件）
🔖 版本化 —— 每个技能多个版本
🧩 打包 —— 校验/解析/生成归档
🔥 预热 —— 之前讲的 skillprewarm 就在这里解析
🌱 内置种子 —— 启动时种入内置技能

第三章 · 技能包结构

一个技能包长什么样？

📦
用户上传 ZIP
SKILL.md + 资源文件（≤ 8 MiB）
▼ 解析
🧩
解析出元数据
frontmatter（name/description）+ 标题 + 首段
▼ 打包
🔖
版本化归档
SHA-256 指纹 + 版本号 + 存对象存储

💡 限制：技能包最大 8 MiB（MaxSkillPackageBytes）， 上传用 multipart 的 files[] 字段，支持单 ZIP 或散文件。

第七章 · Insight

读完代码的深度理解

📦 1. 技能 = ZIP 包 —— 不是配置，是完整文件包（SKILL.md + 资源）： 所以才有 8 MiB 限制、multipart 上传、归档存储。

🔖 2. 版本化 = 不可变归档 —— 每个版本一个 SHA-256 指纹， 内容不可变：Agent 引用的版本永远一致。

🧩 3. 双类型 —— anthropic（内置）+ custom（自定义）： 内置技能系统提供，自定义用户上传，resolver 分流处理。

🔥 4. 和 skillprewarm 深度耦合 —— resolver 的输出就是预热的输入： skills 是"技能仓库"，skillprewarm 是"技能快递员"。

🌱 5. seed 保证开箱即用 —— 启动时种入内置技能， 新部署不需要手动创建基础技能。
