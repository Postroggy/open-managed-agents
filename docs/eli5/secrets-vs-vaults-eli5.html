🔐 secrets vs 🗄️ vaults
到底啥区别？

🔧 一个是"工具"
一个是"业务"
第一章 · 一句话

核心答案

secrets 是加密工具（怎么加密）
vaults 是保险库业务（存什么 + 怎么用）

vaults 依赖 secrets —— vaults import secrets，
调用它的 Seal/Open 来加密凭据。

第四章 · 生活类比

锁匠 vs 银行

🔒 secrets = 保险箱制造商（只造锁和箱子，不管里面装什么）
🏪 vaults = 银行的保管箱业务（决定谁可以存、取时怎么验证）

或者：
📖 secrets = 加密算法的"字典"（AES-GCM 怎么用、DEK/KEK 怎么配）
📁 vaults = 加密算法的"应用"（把 MCP token 存进去、调 GitHub 时取出来）

第六章 · Insight

读完代码的深度理解

🧩 1. 分层是"可替换性" —— secrets 是通用设施： 以后换加密算法（KMS），只改 secrets，vaults 业务不动。

🏗️ 2. vaults 是 secrets 的"最大客户" —— 但不止它用： codesessions、db 也用 secrets（通用加密设施）。

🎯 3. secrets 不知道业务 —— 它只处理字节数组： "加密什么"由调用方决定（vaults 加密凭据，其他包加密别的）。

🔗 4. 单向依赖 —— secrets 绝不 import vaults： 工具层永远不依赖业务层（Go 依赖方向铁律）。

💡 5. 一句话记忆 —— secrets = 锁匠（技术）， vaults = 银行（业务）：银行雇锁匠，锁匠不知道银行存什么。
