第二章 · 完整代码

26 行做了什么？

func Open(ctx context.Context, redisURL string) (*redis.Client, error) {
  // ① URL 必填
  if strings.TrimSpace(redisURL) == "" { return nil, errors.New("redis.url is required") }

  // ② 解析 URL（redis://user:pass@host:port/db）
  options, err := redis.ParseURL(redisURL)

  // ③ 创建客户端
  client := redis.NewClient(options)

  // ④ 立即 Ping 验证连接（失败就关掉）
  if err := client.Ping(ctx).Err(); err != nil {
    _ = client.Close()
    return nil, fmt.Errorf("connect redis: %w", err)
  }
  return client, nil
}

第五章 · Insight

读完代码的深度理解

🪶 1. 极简 = 单一职责 —— 26 行只做"创建连接"： 不封装业务、不搞抽象，就是工厂。

🏠 2. 组装层专用 —— 只有 main.go 调用： 符合"连接池在组装层创建，业务包不自己开连接"的项目规范。

⚡ 3. 启动即验证 —— Ping 检查： Redis 不可用 → 启动就失败（fail fast），而不是运行时才爆。

🧹 4. 失败清理 —— Ping 失败 Close 连接： 不留半开连接（资源不泄漏）。
