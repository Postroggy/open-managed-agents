第一章 · 它是什么

记忆库解决什么问题？

Agent 会话结束后，学到的东西就丢了。
memory 让 Agent 把重要信息 存进长期记忆，下次会话还能用。

internal/memory 提供 记忆库 API（1834 行大文件）：

📚 Memory Store（记忆库）→ 🧠 Memory（记忆条目）→ 📜 Memory Version（版本）

三级结构，每条记忆可版本化、可脱敏、有操作审计。

第五章 · 两个亮点

Precondition 与 Redact

🔒 1. Precondition（乐观锁）
更新记忆时带 content_sha256 —— 只有当前内容指纹匹配才更新。
防止两个 Agent 同时改同一条记忆互相覆盖（lost update）。

🚫 2. Redact（脱敏）
版本可以被 redact —— 把敏感内容"涂黑"，
但保留版本记录（redacted_at + redacted_by 审计），不物理删除。

💡 设计 insight：内容与元数据分离 —— 大内容（≤100KB）存对象存储， DB 只存路径 + SHA-256 指纹 + 元数据。列表接口（view=basic）不读内容，快。
