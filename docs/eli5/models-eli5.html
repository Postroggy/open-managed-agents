第五章 · Insight

读完代码的深度理解

📇 1. 目录是"静态内置"的 —— 不查 DB、不调上游，8 个模型硬编码在代码里： 启动零成本，响应毫秒级。

🔀 2. 映射是"应用层覆盖" —— 内置目录是 Claude 模型， 用户配了映射 → 翻译成上游模型名（BYOK 无缝）。

✨ 3. display_name 同步 —— 翻译后 display_name 也换成上游名， 用户看到的永远是"真实可用的模型名"。

🔍 4. 翻译后去重 —— 两个 Claude 别名映射到同一上游模型时只展示一个， 目录保持干净。

🧩 5. Anthropic 兼容格式 —— data/has_more/first_id/last_id 完全对齐官方 List Models API，SDK 开箱即用。
