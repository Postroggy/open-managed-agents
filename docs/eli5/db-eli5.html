第一章 · 它是什么

数据库里存什么？

整个系统的「持久状态」都在这 —— 60 张表（60 个 mapper），
从账号到对话，从文件到密钥，全在这里。

internal/db 是唯一能访问 PostgreSQL 的地方（Yourbatis Mapper），
其他包都通过它读写数据 —— 它是数据仓库的唯二管理员。

42 个 migration 文件管理表结构变迁（goose）。

第四章 · 设计要点

几个记住的

🔑 每个表都有 uuid 业务标识 + bigint id 内部主键 + external_id（file_xxx 等）
🚫 没有外键 —— 完整性靠应用保证
📜 所有 schema 变更走 goose migration（42 个）
🧹 有专门清理任务表（filestore_cleanup_jobs）给 cleanup 用
